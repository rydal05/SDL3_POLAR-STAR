# Polar Star

A 2D game engine written entirely in C/C++ and Simple DirectMedia Layer 3.

## Features

Memory efficient lightweight entitiy management
Practical usage of programming patterns
Cross-compatible platform compiling code

## Building

Provided in the repo is a zsh/bash script which outlines basic compiling commands. Verified to compile on Arch, Fedora, and Debian. Some implementation-defined behavior prevents it from being compiled without having to mess with the code and make alterations.
